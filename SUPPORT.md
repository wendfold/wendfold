# Support

## Where to get help

Support for Wendfold is by email.

- **Email:** support@wendfold.com
- **Support page:** <https://wendfold.com/support>
- **Documentation:** <https://wendfold.com/docs>
- **Downloads:** <https://wendfold.com/download>

GitHub Issues in the `wendfold/wendfold` repository will be available as an additional channel once the repository is public. Until then, please use email.

## Before you write

Please confirm the problem against the current release, downloaded from <https://wendfold.com/download>, not against a source snapshot.

Wendfold is installed and updated with the suite package, the only installer that is published:

- `pkg_wendfold_vX.Y.Z.zip`

## Questions and usage help

Email support@wendfold.com and describe what you are trying to do, what you expected, and where the documentation was unclear.

## Bug reports

Email support@wendfold.com (or, once the repository is public, use the bug report issue template) and include:

- Wendfold version
- Joomla version
- PHP version
- database engine and version
- how you installed or updated: package ZIP upload, or Joomla's update system
- exact steps to reproduce
- expected result
- actual result
- relevant screenshots or logs

Please leave out member names, email addresses, phone numbers, and other personal data you don't need to show the problem. Never send passwords or administrator logins.

## Security issues

Please do not post security vulnerabilities publicly.
Use the process described in [`SECURITY.md`](SECURITY.md): GitHub private vulnerability reporting, or email security@wendfold.com.

## Support scope

The public project is documented and supported as one product: Wendfold.

Joomla uses separate extension types internally, so the build also produces child ZIPs for the component and plugins. They are internal build outputs that the package carries inside it, and they are never published on their own. Support assumes an install from the package.
